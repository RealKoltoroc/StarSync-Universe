# Release artifacts

Windows release packages are generated by `scripts/publish-win-x64.ps1`.

The generated ZIP/EXE artifacts are intentionally ignored by source Git and should be uploaded as **GitHub Release assets** rather than committed to the repository history. `CHECKSUMS.txt` can remain in the repository as the checksum record for the prepared release.

Current prepared local artifact:

- `StarSyncUniverse_0.7.77_win-x64.zip`
- File version: `0.7.77.0`
- Product version: `0.7.77`

The ZIP is kept in the local `public-git` staging directory for upload, but `.gitignore` prevents an ordinary `git add .` from adding the large binary package to the source repository.
